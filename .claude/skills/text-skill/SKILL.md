# Text Skill (文本处理与优化技能)

## 适用场景

- 用户要求快速清理或检查文档中的错别字与语病。
- 需要将杂乱的文字内容重新提取和结构化（例如转换为 Markdown 列表或表格）。
- 对任意文本进行排版规范调整。
- (针对本项目的 LaTeX 文件) 润色或校对指定的章节内容。

## 工作流

1. **分析文本**：阅读目标文本或文档内容，分析当前的语境和结构。
2. **定位问题**：检查是否存在拼写错误、多余的空格、标点符号误用（如中英文标点混用）等。
3. **优化重构**：
   - 修复格式问题，确保一致性。
   - 提取核心要点，适当时使用列表呈现。
   - 如为翻译或润色请求，保持原意并改进表达。
4. **输出结果**：提供修改后的纯文本或直接帮你应用到目标文件中。

## 注意事项

- 尽量保持文本原有的语意，不要在润色时改变作者的意思。
- 如果是不确定的专业术语，保留原词或询问用户。

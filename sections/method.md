方法
本章将借本节将阐述DRS-DQN算法如何与机器人移动履行系统模型协同实现路径规划。3.1节介绍适用于机器人移动履行系统路径规划问题的DQN算法结构；3.2节详细说明奖励塑造的机制；3.3节详细说明动态场景下的奖励塑造如何构建；3.4节介绍DRS-DQN算法的框架与训练技巧。
RMFS环境建模
在机器人移动履行系统（RMFS）中，环境建模是AGV路径规划的基础，其直接决定机器人能否准确获取自身位置、任务目标以及周围环境等信息。RMFS 场景具有货架排列规律有序、作业流程高度结构化等特征，为了能精确描述RMFS环境空间的拓扑结构，并考虑创建地图的便捷性和AGV路径规划的频繁程度，本研究采用栅格地图对 RMFS 仿真环境进行形式化建模。该方法将空间划分为均匀的网格，每个网格存储一个值，表征货架、拣选站及可通行的通道等区域，实现从连续到离散的建模。在此基础上构建的 RMFS 环境模型不仅可以表示仓库的真实布局，还能够为DQN等深度强化学习算法提供一致且可训练的状态表征。
DQN算法在AGV路径规划中的应用
在基于DRL的路径规划模型中，为适配机器人移动履行系统，需设计三个组成马尔可夫决策过程的核心要素，即状态、动作和奖励，同时也要合理设计神经网络的结构。
3.1.1 状态空间
在强化学习中，状态或观测代表了环境的内部和外部信息及逻辑。在机器人移动履行系统（RMFS）中，运行中的AGV可以获取大量的全局信息，包括场景的物理布局（如拣选站、存储站和轨道的具体位置）、自身当前位置、目标位置及其运行状态。
为了使深度神经网络能够有效处理并学习这些环境特征，本研究基于从环境中提取的信息，构建了四个与RMFS模型尺寸完全相同的矩阵，共同表示系统的当前状态。矩阵中每个位置的取值仅有两种可能：0代表“假（False）”，1代表“真（True）”。这四个矩阵的具体定义如下：
合法位置矩阵（Valid Location Matrix, VLM）：该矩阵表示AGV当前可以合法进入的所有位置。如果AGV能够移动到某个栅格，该处的值记为1；反之，若该栅格不可通行，则记为0。具体判定规则如下：轨道（Track）区域始终允许AGV通行，因此轨道栅格的值恒为1；存储站的值取决于AGV的负载状态：当AGV未载货（空载）时，允许从存储站下方穿过，对应的值记为1；当AGV载有货架（满载）时，不允许穿过存储站，对应的值记为0。拣选站作为稀缺资源，仅当它正是AGV当前的任务目标位置时，其对应栅格的值才为1，在其他任何情况下均为0。
禁行位置矩阵（Forbidden Location Matrix, FLM）：该矩阵的取值与合法位置矩阵（VLM）完全相反，作为补充信息来标明哪些位置可以或不可以通过。即VLM中值为1的位置在FLM中为0，VLM中值为0的位置在FLM中为1。引入这组取值相反的矩阵能够进一步强化当前环境的特征，为神经网络提供更加充分的学习信息。
当前位置矩阵（Current Location Matrix, CLM）：首先初始化一个与RMFS模型尺寸相同的全零矩阵，随后，仅将代表AGV当前所在位置的栅格值修改为1，其余全为0，由此构成CLM。
目标位置矩阵（Target Location Matrix, TLM）：构建方式与CLM相同，在全零矩阵的基础上，仅将代表AGV当前任务目标位置的栅格值修改为1，以此构成TLM。
通过上述四矩阵状态空间的设计，系统将包含动态约束的离散仓库运行环境，成功转化为了包含4×W×H（W,H为地图宽与高）的张量数据，使其可以直接作为卷积神经网络的输入特征。
3.1.2 动作空间
在RMFS 中货架排列呈规则栅格状，AGV主要沿直线通道运动。同时考虑算法复杂度和策略稳定性，本文规定：AGV限定向上、向下、向左和向右四种动作，且保持恒定的线速度。由于神经网络只能以数字形式输出结果，因此为每个动作分配一个数字编码。在运行的系统中，每当AGV进入一个新的区块，就会将观测信息发送给Python程序； DQN算法会向AGV返回一个动作，随后AGV判断该动作是否合法。合法动作会被执行，系统继续运行；而非法动作会导致系统终止运行。其动作空间为A = {Up, Down, Left, Right}。判断动作合法性的规则将结合奖励结构，在接下来的部分进行介绍。
3.1.3 奖励结构
奖励的设定基于AGV执行DQN算法给出的动作所产生的结果，用于评估该动作的价值。这些动作可分为三类：非法动作、正确动作和正常动作，每类动作对应不同的奖励值。
非法动作指无法执行的动作，执行这类动作会导致机器人移动履行系统模型停止运行。以下三种情况对应的动作属于非法动作：（1）动作导致AGV驶出系统区域；（2）动作导致负载AGV撞击存储站；（3）动作导致AGV进入非最终目的地的拣选站。非法动作的奖励值为-100。
正确动作指AGV执行该动作后能够到达最终目的地的动作，例如到达指定的存储站以获取或放置货舱，或到达指定的拣选站。正确动作的奖励值为1。
正常动作指AGV执行该动作后，机器人移动履行系统模型的运行不会终止，但AGV尚未到达最终目的地的动作。正常动作的奖励值为0。正常动作和正确动作统称为合法动作。

3.1.4 神经网络结构
本研究中使用的神经网络（Deep Q Network）采用五层结构，前三层为卷积层（convolutional layers），后两层为线性层（linear layers）。卷积层适用于从图像像素和矩阵中提取特征，并识别其中的一些潜在规律。卷积层包含多个具有可学习权重和偏置的神经元，神经元的数量需要根据输入矩阵的尺寸进行调整，矩阵尺寸越大，所需的神经元数量越多，反之则越少。线性层也称为全连接层（fully connected layer），它有助于改变前一层输出的维度，能够根据线性关系对大量输入信息进行拟合，并输出最终结果。线性层中神经元的数量取决于前一层神经元的数量。
奖励塑造
顾名思义，奖励塑造旨在通过塑造直接从环境中获得的奖励来加速和稳定学习。其通过调整马尔可夫决策过程（MDP）的奖励，引导学习算法朝着期望的行为方向发展。塑造奖励的一般形式为：
█(R^'=R+F#(1) )
其中：
R:S×A×S→ℝ是原始马尔可夫决策过程的期望奖励函数。
F:S×A×S→ℝ是期望奖励塑造函数。
通过将两者相加，得到修正后的期望奖励函数R':S×A×S→ℝ。此时，学习过程不再基于原始奖励R，而是基于修正后的奖励R'，并寻求能最大化修正奖励R'贴现总和的策略。
大量成功案例已证明，奖励塑造是引导智能体产生期望行为的有效工具（Brys、Now、Kudenko和Taylor，2014；Devlin、Kudenko和Grze，2011；Dorigo和Colombetti，1994；Efthymiadis和Kudenko，2013；Mataric，1994）。然而，若使用不当，奖励塑造可能会改变马尔可夫决策过程的最优策略，导致非期望行为。Randløv和Alstrøm（1998）在其研究中给出了一个典型案例：一辆自行车从A点驶向B点，只要智能体向B移动就会获得奖励，其余奖励为0。结果智能体学会了在A附近绕圈的策略，而非朝着目标点B前进。智能体这就引出了一个问题：在不改变原始问题最优策略的前提下，奖励究竟能被调整到何种程度？这一条件被称为策略不变性。
Ng等人（1999）提出了如何调整奖励以确保策略不变性。他们引入了一个势函数ΦS:S→ℝ，该函数将每个状态映射到一个特定值。对于期望状态（例如，遵循目标策略所到达的状态），赋予较高的函数值，反之则赋予较低的值。势函数的灵感来源于物理学中的势能概念，即物体在特定状态下相对于参考状态的势能。利用该势函数，Ng等人（1999）将基于势函数的奖励塑造函数F:S×A×S→ℝ定义为：
█(F(s*t,a_t,s*(t+1) )=γΦ*S (s*(t+1) )-Φ*S (s_t )#(2) )
其中：
γ 为折扣因子。
Φ_S表示当前状态的势函数。
F(s_t,a_t,s*(t+1) )为奖励塑造函数。
Ng等人（1999）证明，在修正后的马尔可夫决策过程<S, A, T, γ, R+F>中最优的策略，在原始马尔可夫决策过程<S, A, T, γ, R>中同样是最优的。其中，S为状态空间，A为行动空间，T为状态转移概率，R为原始奖励函数，F为奖励塑造函数。值得注意的是，只要奖励塑造函数F采用上述基于势函数的特定形式，无论选择何种ΦS，策略不变性都成立。
Wiewiora、Cottrell和Charles（2003）扩展了Ng等人（1999）的研究成果，提出了同时基于状态和行动的势函数，即Φ*SA:S×A→ℝ。这种新的势函数能提供更具体的信息，以引导智能体产生期望行为。实际上，现在可以为状态-行动对赋值，而不再局限于仅为状态赋值。Wiewiora等人（2003）基于势函数ΦS,A提出了两种基于势函数的奖励塑造函数，分别称为前瞻奖励塑造和回溯奖励塑造。前瞻奖励塑造与Ng等人（1999）的方法类似，利用下一状态-行动对（sₜ₊₁, aₜ₊₁）的势函数；而回溯奖励塑造则在基于势函数的奖励塑造函数F:S×A×S×A→ℝ中，利用前一状态-行动对 (s*(t-1),a*(t-1) ) 的势函数 Φ*(S,A) (s*(t-1),a*(t-1) )。本研究采用后者，其定义如下：
█(F(s*t,a_t,s*(t-1),a*(t-1) )=Φ*(S,A) (s*t,a_t )-γ^(-1) Φ*(S,A) (s*(t-1),a*(t-1) )#(3) )
一般而言，难以直接将式（5）代入式（3），因为前者依赖于所遵循的策略。换句话说，采用这种奖励塑造函数时，无法简单地构建一个具有修正奖励函数F+R的新马尔可夫决策过程，因此也无法从理论上证明策略不变性。但存在一个显著的例外情况：当所遵循的策略是平稳策略时（相关理论证明可参考Wiewiora等人（2003））。原因在于，在期望意义下，当策略固定时，前一状态-行动对的势函数是可计算的。因此，在平稳策略π下，可定义R'=R+Fπ（其中Fπ表示对所遵循的平稳策略的依赖），并证明策略不变性成立。
在本研究中，深度Q网络算法在每次训练中都会更新，导致所遵循的策略并非平稳策略（因此无法从理论上证明策略不变性）。然而，后续的实证结果表明，经过塑造的深度Q网络算法有时能超越教师策略的性能，这暗示策略不变性实际上可能成立（尽管目前尚无相关证明）。
本研究采用Wiewiora等人（2003）提出的回溯式基于势函数的奖励塑造方法，根据教师策略定义势函数ΦS,A。研究建议采用已知的启发式算法作为教师策略，以引导深度Q网络算法的学习。用a†(s)表示教师策略在状态s下采取的行动，将势函数ΦS,A定义为：
█(Φ*(S,A) (s,a)=-k|a^† (s)-a|#(4) )
其中k∈ℝ⁺是一个可任意选择的参数，用于增强教师策略的引导作用。因此，在状态s下采取的行动a与教师策略推荐的行动a†(s)之间的差异越大，势函数值就越低。将该势函数代入Wiewiora等人（2003）提出的回溯式基于势函数的奖励塑造函数（见式（3）），就能间接鼓励智能体采取与教师策略一致的行动。
目前，尚无证据表明当使用神经网络近似价值函数时，所得到的策略会收敛到最优策略。因此，以往关于基于势函数的奖励塑造的文献主要集中于（表格型）强化学习。本研究将基于势函数的奖励塑造应用于深度强化学习，尽管无法从理论上做出相关证明，但实证结果表明，在深度强化学习中，策略不变性仍然成立。
动态势能奖励塑造
3.4.1理论基础：从静态到动态
传统的势能基础奖励塑造（PBRS）假设势能函数 Φ(s) 是静态的。然而，在 RMFS 动态场景中，障碍物的实时移动会导致最优路径拓扑结构发生改变，若继续沿用静态A* 计算距离，会导致引导信号失效甚至误导。
为了解决这一问题，本研究引入Devlin 和 Kudenko (2012) 提出的动态势能基础奖励塑造（Dynamic PBRS）理论。他们证明了传统的势能基础奖励塑造可以被放宽：只要塑造的奖励 F 遵循特定的差分形式，即势能函数 Φ(s,t) 随时间 t 动态变化，那么不会改变最优策略。
动态 PBRS 的一般形式定义为：
█(F(s,t,s^',t^' )=γΦ(s^',t^' )-Φ(s,t)#（5） )
其中，s,s^' 为状态，t,t^' 为对应的时间步，γ 为折扣因子。这一理论为在深度强化学习中引入 D* Lite 动态规划提供了理论保证。
3.4.2基于 D* Lite 距离场的势能函数
与 A* 不同，D* Lite 通过维护每个节点的 g(s) 值和 rhs(s) 值，来识别环境变化对路径的影响。g(s) 值表示从当前节点 s 到目标点的路径代价，只有在算法显式更新节点时才会改变。rhs(s)则是基于当前节点 s的所有邻居节点〖 s〗^' 的 g(s^' ) 值，加上它们之间的移动代价 c(〖s，s〗^' ) 计算出来的当前最优估计值。它代表了结合当前环境（比如有没有新障碍物阻断路）后，节点 s 到目标的实际潜在距离。
D* Lite其核心优势在于增量式重规划。当环境中的边代价发生变化（如探测到动态障碍物）时，D* Lite 不会重置搜索，而是利用上一次搜索保留的优先队列，仅更新那些因环境变化导致 g(s)≠rhs(s) 的“不一致”节点。这使得算法仅需修复受影响的局部区域，而非重新计算全局路径。
同时D* Lite 通常采用从目标点向起始点的反向搜索方式。这意味着算法维护的是以目标为中心的距离场（Distance Field）。无论 AGV 移动到哪个位置，D* Lite 都能实时提供该位置到目标的真实代价估计。
不同于传统方法利用教师动作进行引导，本研究利用 D* Lite 算法维护的距离场（Distance Field）作为势能来源。D* Lite 是一种增量式启发式搜索算法，专门用于在环境部分发生变化时利用上一次的搜索结果进行快速重规划。
我们定义时刻 t 的动态势能函数 Φ(s,t) 为 D* Lite 计算的路径代价的负相关函数：
█(Φ(s,t)=-ω(η)⋅g*(D^_ ) (s,t)#（6） )
其中：
g\_(D^_ ) (s,t)：表示 D* Lite 算法在时刻 t 维护的从当前状态 s 到目标点的实际路径代价（即 rhs 值）。当环境出现动态障碍物时，D* Lite 仅更新受影响节点的 g 值，从而实时且低成本地修正距离场。
ω(η)：是随训练进程动态变化的势能权重系数，η 表示当前的训练回合数（Episode）。
将势能函数代入塑造公式（5），得到智能体获得的最终塑造奖励 F：
█(F*t=ω(η)⋅[g*(D^_ ) (s,t)-γ⋅g\_(D^_ ) (s^',t^' )]#（7） )
该公式的物理含义为：当智能体向 g 值更小（即距离目标更近）的区域移动时，将获得正向的势能差奖励，从而形成密集的梯度引导奖励。
3.4.3 动态势能的延迟计算与优先经验回放
在动态环境下，环境随时间变化：t 的动态势能函数为 Φ(s,t)。传统的做法是将塑造后的奖励R^'=R+F直接存入经验回放池。然而，由于 DQN 的离线特性，当旧样本被采样时，其存储的势能引导可能已不再适用于当前的环境状态（例如动态障碍物已移动）。此时，样本中计算的势能引导将与当前环境产生偏离，不仅无法起到正确的启发式引导作用，反而会提供错误的奖励梯度，误导神经网络的更新。
为了解决动态环境下经验过时问题，考虑使用Hindsight Experience Replay (HER)中的奖励重标签方法。Replay Buffer 只存状态s、动作a、新状态 s'、环境原始奖励r。当网络进行梯度下降时，利用当前最新的 D* Lite 地图计算Φ(s,t)和Φ^' (s,t)，算出F，加到Target Q值上。这种延迟计算机制确保了无论经验存放了多久，其在被用于网络参数更新时，始终能够反映当下最新、最准确的避障拓扑引导。
现在计算损失函数时会乘以重要性采样权重。在普通的 DQN 中，样本是均匀随机抽取的，网络看到的样本分布等同于环境真实的分布。 但在 PER 中，我们人为地频繁抽取那些高优先级（TD-Error大）的样本。样本被选中的概率P(i)很低，我们给它一个正常或较大的权重，以此更好的观察损失函数。

神经网络能够通过学习迭代拟合高维输入，但有多个超参数会对训练过程产生影响，甚至可能决定神经网络能否收敛。在这些超参数中，学习率和探索率最为关键，它们对训练过程的影响极大，具体将在下文详细说明。
（1）学习率
学习率与损失值共同决定了神经网络参数的变化幅度。大多数强化学习算法（包括DQN算法）在优化神经网络参数权重时，都会采用梯度下降算法，该算法依靠学习率和梯度这两个参数来调整权重。权重的迭代更新方式如公式（9）所示，其中θ_j代表权重，ΔJ(θ)/(Δθ_j )代表梯度。学习率过小时，学习进程会变慢；学习率过大时，虽然能加快训练速度，但更容易出现无法收敛甚至发散的情况。此外，梯度是通过代价函数和损失值计算得出的，损失值的计算如公式（10）所示。在该公式中，r_t+GAMMA⋅Max*(a*(t+1) ) Q(s*(t+1),a*(t+1) )代表神经网络对当前状态值的预测，它由实际奖励值（r_t）和未来奖励值的期望（Max*(a*(t+1) ) Q(s*(t+1),a*(t+1) )）两部分构成；Q(s_t,a_t )代表神经网络对当前状态值的完整预测。这两部分的差值代表基于奖励值得到的状态值与完整预测状态值之间的差异，也就是损失值。

（2）探索率
探索率（exploring rate）决定了使用A算法进行决策的概率，以及停止使用A算法进行探索的时机（停止探索后，算法完全依靠神经网络进行决策）。探索率越大，使用神经网络进行决策的概率越高，而（1-探索率）则代表使用A算法进行决策的概率。例如，当探索率的值为0.8时，使用神经网络进行决策的概率为80%，使用A算法进行决策的概率为20%。训练的目标是使神经网络收敛，能够根据输入的观测信息做出正确决策，因此在训练初期，使用D* lite算法的频率较高，随着训练的推进，其使用频率逐渐降低。重要的是，必须尽早停止使用D* lite算法，完全依靠神经网络进行决策，以确保神经网络最终能够收敛。图展示了探索率的变化情况，横轴代表训练回合数（训练回合总数会根据机器人移动履行系统的规模不同而有所差异），纵轴代表探索率的取值。在训练前30%的回合中，探索率固定为0.8；在训练回合数从30%到80%的过程中，探索率从0.8逐渐增加到1；当训练回合数超过80%后，探索率固定为1，此时D* lite算法不再参与决策过程，所有决策均由神经网络做出。

（3）终止条件
终止条件决定了训练过程何时结束。在本研究中，训练的终止条件并非固定的训练回合数，而是神经网络连续做出正确决策的次数。
当神经网络连续做出正确决策的次数达到预设的阈值时，训练过程结束。该阈值的设置需要根据机器人移动履行系统的规模和复杂度进行调整，以确保神经网络能够充分学习并达到收敛。
